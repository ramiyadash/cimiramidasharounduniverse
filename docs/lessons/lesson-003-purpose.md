**21st July 2026 :**
**One idea I'd like to keep in mind as we continue is something we've naturally been doing: every change should answer one of three questions:**

Does this make the product more intuitive?
Does this make the architecture cleaner?
Does this make future features easier to build?
Does it protect the user’s security and privacy?

**Security and privacy as a fourth design question for every feature:**

Does this expose personal or trip information unnecessarily?
Is any user data being sent to a third party?
Are we storing more information than we need?
Could the UI reveal sensitive details on a shared screen?
